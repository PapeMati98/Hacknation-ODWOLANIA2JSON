## Do zrobienia przed oddaniem

- [x] Nazwa zespołu w polu 7 jest zgodna z nazwą wybraną przez drużynę.
- [ ] Wkleić przygotowany opis problemu z liczbą odwołań do KIO.
- [x] Wysłać zaproszenia do prywatnego repo trzem kontom wskazanym przez UZP.
- [ ] Sprawdzić przyjęcie zaproszeń przez jurorów.
- [ ] Uzupełnić instrukcję uruchomienia (pole 17)
- [ ] Wgrać prezentację PDF ≤ 10 MB (pole 18)
- [ ] Opcjonalnie dodać okładkę 800×600 (pole 10)
- [x] Opcjonalnie: wideo na YouTube jako *Listed* (pole 15)
- [ ] Zaktualizować „What's done so far” o końcowe wyniki
