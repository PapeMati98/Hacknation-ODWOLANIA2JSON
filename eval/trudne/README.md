# Trudne przykłady do oceny

Wgraj PDF do osobnego folderu sprawy, np. `eval/trudne/sprawa_01/odwolanie.pdf`. Kilka dokumentów tej samej sprawy może leżeć razem. Prosimy o pliki, które można udostępnić zespołowi i jury.

Jeśli masz sprawdzony wzorzec, dodaj go obok PDF-u pod tą samą nazwą, z rozszerzeniem `.json`, np. `sprawa_01/odwolanie.json`. Możesz dodać sam PDF. Wzorzec będzie potrzebny dopiero do pomiaru zgodności pól.

Aby przetworzyć te pliki, można podać aplikacji `--input eval/trudne`. Do obliczenia F1 na opisanych przykładach zespół wskaże PDF-y i wzorce w manifeście przekazanym do narzędzia oceny. [Narzędzie oceny](../../tools/score.py)
